■ JOYFIT24 経堂アンケート — Google Apps Script 完全版セットアップ

【場所】スプレッドシート → 拡張機能 → Apps Script
https://docs.google.com/spreadsheets/d/1h_hG-ac0DwPLLPuxsMNf4umsgQjJkv7bdTE69eATqIQ/edit

【このフォルダのファイルをそのまま使う】
  Code.gs          … メイン（VOL.1 + VOL.2 + ダッシュボード集計）
  Dashboard.html   … VOL.1 集計画面（doGet 用）
  appsscript.json  … 権限スコープ定義（下記手順で反映）

────────────────────────────────────────
1. Code.gs
────────────────────────────────────────
  ・既存の Code.gs / コード.gs を開く
  ・中身をすべて削除
  ・このフォルダの Code.gs を全文コピー＆貼り付け
  ・保存（Ctrl+S）

────────────────────────────────────────
2. Dashboard.html
────────────────────────────────────────
  ・左の「＋」→ HTML → ファイル名を Dashboard に
    （既に Dashboard.html があれば中身を全文差し替え）
  ・このフォルダの Dashboard.html を全文コピー＆貼り付け
  ・保存

────────────────────────────────────────
3. appsscript.json（Drive 権限の明示）
────────────────────────────────────────
  ・左の歯車「プロジェクトの設定」
  ・「appsscript.json」マニフェストをエディタで表示する にチェック
  ・左に appsscript.json が出る → このフォルダの内容で差し替え
  ・保存

────────────────────────────────────────
4. Drive 権限の初回許可（VOL.2 画像添付に必須）
────────────────────────────────────────
  ・関数プルダウンで authorizeVol2Drive を選択 → 実行
  ・「権限を確認」→ 許可
  ・実行ログに OK: Drive folder = ... と出れば完了

────────────────────────────────────────
5. Webアプリの再デプロイ
────────────────────────────────────────
  ・デプロイ → デプロイを管理 → 鉛筆アイコン
  ・バージョン → 新バージョン → デプロイ
  ・URL（.../exec）は変えないこと

  推奨設定:
    次のユーザーとして実行: 自分
    アクセスできるユーザー: 全員

────────────────────────────────────────
【動作】
  VOL.1 → シート「responses」
  VOL.2 → シート「responses_vol2」（自動作成）
  VOL.2 画像 → Drive「JOYFIT24経堂_アンケートVOL2_参考画像」
  ダッシュボード → Webアプリ URL をブラウザで開く（doGet）
